# Coordinate system of simulation

(x,y,z) = (0,0,0) is positioned in the bottom, back, left corner

x is the axis that runs left-right
y is the axis that runs back-front
z is the axis that runs bottom-top

If you place a particle at (1.0,1.0,1.0) this is where its centre will be placed
If you place a box at (1.0,1.0,1.0) this is where the object will be centred.
